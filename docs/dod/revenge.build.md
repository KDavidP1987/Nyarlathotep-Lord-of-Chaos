## Components
- C1 · **Heat and warnings** a player who keeps killing one faction's people is warned privately, step by step, before that faction strikes back · D1 D3 D4 D10 D18 D20
- C2 · **The revenge start** revenge starts for that player alone, when the player is out in the world, never twice at once on one player, and then rests for a cooldown · D5 D13 D19
- C3 · **Ambush tiers around the target** growing hunt squads come for the target only, never into claimed territory · D2 D6 D14 D19
- C8 · **Bosses in the last wave** any wave event can end on chosen bosses that join only its final wave and never set off another event (design §9 D51) · D28 D29 D30 D31 D32
