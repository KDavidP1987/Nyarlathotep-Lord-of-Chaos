# Build view: Wave variety — pursuit, unit and boss pools, timed and onslaught templates, wider allied groups

Generated from `wave-variety.md` by `dod-wbs.mjs --build`; it is not the source of truth. Change the plan, then run `--build` again.

**North Star:** a server admin can make any wave event chase players who run from it, draw each wave's units and bosses at random from named pools, and start 14 new ready-made timed and onslaught events built on wider, in-game-checked allied groups, shipped in the Halloween release 0.13.0 with apocalypse; finished when D1-D24 have evidence.
