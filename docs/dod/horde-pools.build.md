# Build view: Horde pools — full-size hordes, a castle-territory switch for hordes, and a shared faction pool library

Generated from `horde-pools.md` by `dod-wbs.mjs --build`; it is not the source of truth. Change the plan, then run `--build` again.

**North Star:** an admin on a default cfg gets a horde of the size the event asks for (up to 500), keeps castles safe from hordes unless they switch `allowTerritory` on per event, and links any event to shared faction unit and boss pools with a random count, without copying unit lists between events; shipped in the next minor release; finished when D1-D18 have evidence (D13 may wait on the owner).

Risk: (none stated)

## Components
- C1 · **Full-size hordes** the three horde types reach the size their definition asks for on a default cfg, held only by the global tracked cap · D1 D2 D12
- C2 · **Castle switch for hordes** castles are a refuge from hordes unless the event's `allowTerritory` is on · D3 D4 D12
- C3 · **Shared faction pools** a library of faction unit and boss pools, seeded from the allied groups, editable, linked into any event with a random count, and readable in chat · D5 D6 D7 D8 D12
- C4 · **Safe to ship** contract stated, controls registered, privacy kept, owner's judgement, drilled rollback, recorded release · D9 D10 D11 D13 D14 D15 D16 D17 D18
