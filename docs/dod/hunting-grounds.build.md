# Build view: Hunting grounds — region-bound spawns, a region lock and a region hunt by hidden jumps

Generated from `hunting-grounds.md` by `dod-wbs.mjs --build`; it is not the source of truth. Change the plan, then run `--build` again.

**North Star:** a server admin can bind a wave event to named map regions (spawn anywhere in them, keep the units in them, and have the units hunt the players inside them by jumps no player sees), using the existing SpawnWaves locations and caps, with nothing left behind at any end, released as 0.11.0 before revenge and before 2026-10-31; finished when D1-D32 have evidence.

Risk: (none stated)

## Components
- C1 · **Region roam spawn** a wave spread over its scope regions on walkable ground, the owner's mode 1 spawn, with a ready-made spider hunting grounds · D1 D4 D16 D21 D27
- C2 · **Region lock** an event's own units brought back inside its regions and kept off players outside them, and a broken check never breaks the event · D2 D5 D6 D22 D26 D27
- C3 · **Region hunt** each group goes after the nearest eligible player in its regions, by jumps nobody sees beyond the game's reach and by the game's own aggro within it; the mover apocalypse reuses · D3 D7 D8 D9 D20 D24 D26 D27
